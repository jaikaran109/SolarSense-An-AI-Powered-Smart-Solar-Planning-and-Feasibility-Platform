# Security Policy

## Supported Versions

The project currently supports the latest `main` branch and actively maintained changes in this repository.

## Reporting a Vulnerability

If you discover a security vulnerability, please do not open a public issue.

Instead, report it privately by contacting the repository maintainer through GitHub Security Advisories or by emailing the project owner directly if that channel is available.

Please include:

- a description of the vulnerability
- affected files or components
- steps to reproduce the issue
- potential impact
- any suggested mitigation or fix

We will review the report and respond as quickly as possible.

## Responsible Disclosure

We ask contributors to:

- avoid exposing sensitive information in public discussions
- provide enough detail to reproduce and validate the issue
- allow a reasonable amount of time for a fix before public disclosure

## Security Best Practices

This project should be used with secure configuration practices, including:

- keeping environment variables private
- not committing secrets or credentials
- using secure credentials for MongoDB, AI services, and deployment environments
- validating and sanitizing user input
- keeping dependencies updated

## Scope

This policy applies to the application code, configuration files, and deployment setup within this repository.

Thank you for helping keep SolarSense secure.
